# NgToolbox
NgToolbox is a collection of utility functions and helpers for Angular applications. It provides a set of tools to enhance productivity and streamline common tasks in Angular development.

## [Demo](https://stackblitz.com/~/github.com/kamazowe/ng-toolbox)

## [Common Helpers](./src/lib/common/README.md)

This module provides a set of tools to help you manage types, ensure type safety, and simplify common operations when working with TypeScript.

## [Angular Resource API Helpers](./src/lib/resource/README.md)

This module contains a set of utility functions designed to work with the Angular Resource API. These utilities simplify the process of composing, merging, and transforming resources in a reactive and functional way.
